# Retail / E-commerce Orders Pack Analyst

Industry context for retail/e-commerce order data — orders, customers, shipping, payments, and product line items.

Generated by [MIS Plugin Forge](https://github.com/) — a Claude Code/Desktop plugin, ready to install directly from this repo.

## Install in Claude Code or Claude Desktop

```text
/plugin marketplace add karthik-depasolutions/retail-ecommerce-mis-plugin-v1
/plugin install retail-ecommerce-mis-plugin@retail-ecommerce-mis-plugin-v1
/reload-plugins
```

## Before first use

This plugin reads live from a database - there is no bundled `data/` folder. Set the following in the environment Claude Desktop/Code launches from, using the connection string you were given when this plugin was generated (it is never stored in this repo):

```bash
export FORGE_SOURCE_DB_URL="<connection string given to you separately>"
```

Plugin version `0.1.0`. See `plugins/retail-ecommerce-mis-plugin/README.md` for the KPIs and setup notes bundled with this specific plugin.
