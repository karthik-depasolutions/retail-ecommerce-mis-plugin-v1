# retail-ecommerce-mis-plugin

Version 0.1.0. Generated by MIS Plugin Forge for the **Retail / E-commerce Orders Pack** industry pack.

## Setup

Install this plugin from its GitHub marketplace. Claude Desktop/Code start the hosted MCP from `.mcp.json` automatically — no local Python and no `claude_desktop_config.json`.

## Available KPIs

- `average_order_value` - Average Order Value
- `cancellation_rate` - Order Cancellation Rate
- `monthly_revenue_trend` - Monthly Revenue Trend
- `orders_by_payment_channel` - Orders by Payment Channel
- `return_rate` - Return Rate
- `revenue_by_customer_tier` - Revenue by Customer Tier
- `revenue_by_location` - Revenue by Location
- `total_revenue` - Total Revenue
